# 탕정 84B 3D 인테리어 뷰어

더샵 탕정인피니티시티 1차 84B(105동 2901호) 평면 치수로 만든 3D 인테리어 시뮬레이터입니다.

- 파일: `index.html` 단일 파일 (평면도 이미지 내장, Three.js는 CDN에서 불러옴)
- 조작: 한 손가락 드래그 = 회전, 두 손가락 = 확대/이동, 우하단 '설정 열기' = 패널
- 프리셋 3종: 아트월 TV / 반대벽 TV(29층 뷰) / 초단초점 빔프 + 스크린

## 반영된 세대 조건 (2026-11-16)
- **좌우 반전**: 분양 평면도와 대칭인 세대라 3D 공간·평면도 겹쳐보기 이미지를 모두 좌우 반전
  (침실1·발코니1·드레스룸·다용도실 왼쪽 / 현관·케어룸·욕실1·침실2·침실3 오른쪽)
- **서쪽 현관 돌출부**: 분양 평면도처럼 현관 블록이 침실 블록보다 약 0.95 m 서쪽으로 돌출되고, 복도가 현관 앞까지 이어짐
- **주방확장**: 알파룸↔주방/식당 경계 벽 제거 → '주방/식당 (확장)' 하나로 통합.
  북쪽 창가 벽에 싱크볼·개수대·상부장, 동쪽(다용도실·욕실2와 맞닿은) 벽에 냉장고장·키큰장
- **T자형 주방 아일랜드**(프리미엄 키친): 북쪽 창가 메인 상판 앞면에 직교로 맞붙어 거실/식당 쪽으로
  뻗는 아일랜드(0.95 × 1.67 m)와 그 위 인덕션·디자인후드. 식탁은 아일랜드와 나란히 서쪽에 배치
- **침실1(안방) 출입구**: 거실 아트월 북쪽 끝(욕실2 남벽 바로 아래)에 폭 0.75 m 문 — 문틀·열린 문짝·문턱 포함
- **욕실1(공용욕실)**: 펜트리와 헷갈리지 않도록 그대로 유지 — 약 2.0 × 1.5 m, 욕조·양변기·세면대·거울·샤워수전
- **케어룸**: 현관 옆 **펜트리 자리**(약 1.4 × 1.5 m)를 케어룸으로 구성 — 낮은 세척 볼·케어 벤치·벽걸이 수납·바닥 배수구·안전손잡이

## 마감재·색감 (더샵 84A MH 견본세대 기준)
공식 마감재리스트상 84B는 '미견립세대'라, 같은 마감재가 적용된 84A 견본세대 사진을 기준으로 반영했습니다.
- 마루: 강마루 'Life Oak'(사트데코 14-10946-118)
- 아트월: 동평 YF272891 400×800 라임스톤 타일 (3D에 타일 줄눈 텍스처로 구현)
- 주방: 상부장 화이트 · 하부장 샌드그레이 · 상판 엔지니어드스톤(RU608 소피아)
- 벽: 서울벽지 382-1 아이보리 톤, 거실 LED 50W×3 + 간접조명 느낌의 따뜻한 조명

## 평면도 겹쳐보기
`분양 평면도 겹쳐보기`는 평면도 이미지의 실제 축척(안쪽 가로 609 px = 12.85 m)에 맞춘 **균등 배율**로 깔립니다.
2026-11-16 이전 버전은 가로·세로 배율이 서로 달라 벽과 어긋났습니다.
