# 탕정 84B 3D 인테리어 뷰어

더샵 탕정인피니티시티 1차 84B(105동 2901호) 평면 치수로 만든 3D 인테리어 시뮬레이터입니다.

- 파일: `index.html` 단일 파일 (평면도 이미지 내장, Three.js는 CDN에서 불러옴)
- 조작: 한 손가락 드래그 = 회전, 두 손가락 = 확대/이동, 우하단 '설정 열기' = 패널
- 프리셋 3종: 아트월 TV / 반대벽 TV(29층 뷰) / 초단초점 빔프 + 스크린

## 반영된 세대 조건 (2026-11-16)
- **좌우 반전**: 분양 평면도와 대칭인 세대라 3D 공간·평면도 겹쳐보기 이미지를 모두 좌우 반전
  (침실1·발코니1·드레스룸·다용도실 왼쪽 / 현관·팬트리·케어룸·침실2·침실3 오른쪽)
- **주방확장**: 알파룸↔주방/식당 경계 벽 제거 → '주방/식당 (확장)' 하나로 통합, 아일랜드·식탁 배치
- **케어룸**: 공용욕실(욕실1)을 케어룸 구성으로 변경(샤워부스·케어 벤치·안전손잡이)

## 마감재·색감 (더샵 84A MH 견본세대 기준)
공식 마감재리스트상 84B는 '미견립세대'라, 같은 마감재가 적용된 84A 견본세대 사진을 기준으로 반영했습니다.
- 마루: 강마루 'Life Oak'(사트데코 14-10946-118)
- 아트월: 동평 YF272891 400×800 라임스톤 타일 (3D에 타일 줄눈 텍스처로 구현)
- 주방: 상부장 화이트 · 하부장 샌드그레이 · 상판 엔지니어드스톤(RU608 소피아)
- 벽: 서울벽지 382-1 아이보리 톤, 거실 LED 50W×3 + 간접조명 느낌의 따뜻한 조명
